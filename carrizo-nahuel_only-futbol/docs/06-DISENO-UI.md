# Diseño UI - Only Futbol

## Objetivo
La interfaz debe ser moderna, deportiva, sencilla y coherente con la identidad de Only Futbol

## Pantallas
- **Inicio:** logo, navbar, imagen principal, presentación, productos destacados y footer
- **Productos:** catálogo, imágenes, nombre, equipo, precio, búsqueda y filtros
- **Detalle de producto:** imagen, descripción, precio, talle y stock
- **Equipos:** clubes y selecciones disponibles
- **Nosotros:** historia y objetivo del emprendimiento
- **Contacto:** información de contacto y formulario
- **Login y registro:** formularios de acceso
- **Panel de administración:** gestión de productos, categorías, stock y pedidos

## Identidad visual
- Azul oscuro `#0B1F3A`: encabezados y fondos
- Azul `#1464F4`: botones y acciones principales
- Blanco `#FFFFFF`: fondos y textos sobre fondos oscuros
- Gris claro `#F2F4F7`: fondos secundarios

## Botones
Deben tener texto claro y estados visibles para hover, foco y deshabilitado

## Tarjetas
Cada tarjeta de producto puede incluir imagen, nombre, equipo, precio y boton para ver detalles

## Formularios
Deben incluir etiquetas claras, validacion y mensajes de error comprensibles

## Responsive
La interfaz debe adaptarse a computadoras, tablets y celulares. Bootstrap puede utilizarse para facilitar esta adaptacion
