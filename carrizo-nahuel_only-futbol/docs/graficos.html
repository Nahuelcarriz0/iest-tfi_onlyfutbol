El ciclo SDD en Only Futbol

Tres funcionalidades recorrieron el ciclo: catálogo, base de datos y formulario. Cada número suma las tres.

  1. Fase 0

    Constitución

    8principios

    Reglas verificables para todo el proyecto. docs/CONSTITUCION.md

  2. Fase 1

    Spec

    22requisitos y 10 historias

    Qué debe hacer cada funcionalidad, en formato EARS. spec.md

  3. Fase 2

    Clarificación

    40hallazgos

    La IA revisa como QA y el estudiante decide. clarificacion.md

  4. Fase 3

    Plan

    22filas, una por requisito

    Cómo se construye, sin código. plan.md

  5. Fase 4

    Tareas

    28tareas con "Listo cuando"

    Pasos chicos y comprobables. tasks.md

  6. Fase 5

    Implementación

    7commits en el repositorio

    El código del sitio y sus documentos, guardados con Git.

  7. Fase 6

    Validación

    22requisitos revisados

    18 cumplen y 4 tienen prueba manual aprobada. verificacion.md

  8. Si un requisito cambia, se vuelve a la spec: primero se actualiza el documento y después el código.
