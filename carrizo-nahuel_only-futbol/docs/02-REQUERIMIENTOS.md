# Requerimientos - Only Futbol

## Requerimientos funcionales

| ID | Requerimiento | Prioridad |
|---|---|---|
| RF01 | Mostrar la pagina principal | Alta |
| RF02 | Mostrar el catalogo de productos | Alta |
| RF03 | Mostrar el detalle de cada producto | Alta |
| RF04 | Mostrar imagenes de productos | Alta |
| RF05 | Navegar entre secciones | Alta |
| RF06 | Mostrar categorias | Media |
| RF07 | Buscar productos | Media |
| RF08 | Filtrar productos | Media |
| RF09 | Registrar usuarios | Media |
| RF10 | Iniciar sesion | Media |
| RF11 | Crear pedidos | Media |
| RF12 | Consultar los pedidos propios | Media |
| RF13 | Permitir al administrador gestionar productos | Alta |
| RF14 | Permitir al administrador gestionar pedidos | Media |
| RF15 | Mostrar informacion de contacto | Media |

## Requerimientos no funcionales
- **RNF01 - Usabilidad:** la aplicacion debe ser sencilla
- **RNF02 - Responsive:** debe adaptarse a celulares, tablets y computadoras
- **RNF03 - Rendimiento:** debe evitar recursos innecesarios
- **RNF04 - Diseño:** debe respetar la identidad visual
- **RNF05 - Mantenimiento:** el codigo debe estar organizado
- **RNF06 - Compatibilidad:** debe funcionar en navegadores actuales
- **RNF07 - Seguridad:** no debe exponer informacion sensible
- **RNF08 - Escalabilidad:** debe permitir agregar nuevas funciones
